## REGLAS SIGMA
Las reglas Sigma son un formato estándar y neutral (escrito en YAML) que permite a los equipos de ciberseguridad definir patrones de detección de amenazas para analizarlos en registros o logs. Funcionan para el análisis de registros de manera similar a como lo hacen las reglas YARA para la detección de archivos   

La gran ventaja de las reglas Sigma es que son independientes de la plataforma. Utilizando herramientas de traducción como Uncoder.IO o el convertidor nativo de Sigma, una misma regla escrita para la técnica de ejecución de PowerShell puede convertirse automáticamente al lenguaje específico de búsqueda de herramientas como Splunk, Microsoft Sentinel o Elastic (Kibana).

💡En este repositorio en contrarás:
1. Una colección de 50 reglas SIGMA.
2. Enlaces a otros repositorios de reglas SIGMA.
3. Enlaces a conversores de reglas SIGMA según la plataforma que operes.
4. Algunos enlaces a artículos de interés.
